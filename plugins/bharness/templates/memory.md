Ce fichier est lu par tous les agents Bharness au début de chaque session. Il contient ce qu'il faut savoir sur ce projet et sur son utilisateur pour bien travailler.

Règles d'écriture :
- une entrée = une ligne, datée, avec l'agent qui l'a écrite : `- 2026-10-09 · Ada · …` ;
- court et actionnable (« Faire X », « Ne pas faire Y, parce que Z ») ;
- jamais de secret (clé, mot de passe) ;
- une consigne de l'utilisateur prime sur tout le reste ;
- quand une entrée devient fausse, la corriger ou la supprimer plutôt qu'en ajouter une contradictoire.
